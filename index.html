Over mij

Ik ben Guillermo, 24 jaar, en heb veel passie voor programmeren. Ik vind het bijzonder dat je met code iets kunt bouwen dat helemaal aansluit bij je eigen ideeën. Mijn doel is om een leerwerkplek te vinden waar ik begeleid kan worden door een ervaren developer. Ik wil graag van iemand met ervaring leren, nieuwe technieken ontdekken en mezelf stap voor stap ontwikkelen tot een goede software developer.

Ik leer graag nieuwe dingen, werk nauwkeurig en vind goede communicatie belangrijk wanneer je samen aan een project werkt. Ook sta ik open voor feedback, omdat ik geloof dat je daarvan kunt leren en jezelf steeds verder kunt verbeteren.

In mijn vrije tijd kijk ik graag naar voetbal en doe ik aan fitness. Ik ben op zoek naar een leerwerkplek waar ik mijn kennis in de praktijk kan brengen, ervaring kan opdoen en mezelf verder kan ontwikkelen als software developer.
